# 2026-11-22

## Docker 部署改为反代友好模式（VuePress 博客 E:/neverland）

需求：不指定域名，通过反向代理访问。域名与 HTTPS 交给外层反代（群晖 DSM 反代 + Let's Encrypt），容器只做纯 HTTP 静态服务。

### 改动（4 文件，commit 104241914，已 push origin/main）
- **nginx.conf / nginx.dev.conf**：统一为通用配置 —— `listen 80 default_server` + `server_name _`
  （任意 Host 命中）；去掉 443 SSL / 证书 / 80→https 301 跳转；新增 `absolute_redirect off`
  （反代下重定向不写容器内协议/端口）；**保留 `gzip_static always` + `gunzip on`**
  （资源在构建期压成 .gz 且删了原文件，丢了会 404）。
- **Dockerfile**：去掉 `COPY certs` 两处、`EXPOSE 80 443` → `EXPOSE 80`，镜像不再含证书。
- **docker-compose.yml**：去掉 `nginx.dev.conf` 挂载（两份配置已一致，直接用镜像内 default.conf），端口 8080:80 不变。

### 关键提醒
- 反代配置：把后端指向容器的 **80 端口**即可；容器内不再处理域名/TLS。
- 两份 nginx 配置必须同步（都含 gzip_static），否则资源 404。
- 部署需重跑 release.bat 重建镜像才生效（HTTPS 证书改由反代侧管理，certs/ 目录留仓库但不再进镜像）。

### 环境坑（本次验证受阻）
- Docker Desktop 隔几天会关闭；启动后上下文曾切换（本地镜像变成 tools/dotnet 一组，blog/node/nginx 镜像全没了）。
- Docker Desktop 未继承沙箱代理（当前 `127.0.0.1:57381`，端口每会话变），拉 Docker Hub 走 IPv6 超时；
  而该沙箱代理对 docker.io/npmjs 均返回 502，公网直连也失败 → **本次外网完全不通，无法重新构建做运行时验证**。
- 退而做静态验证：两份配置指令一致、Dockerfile 无 certs/443 引用、全仓库配置无域名残留；通过后才提交。
- 结论：配置改动是标准写法且与上轮已验证版本仅差"去 SSL/domain + 加 absolute_redirect off"，风险低；运行时验证待网络恢复或用户本地执行。

## release.bat 发布失败修复（同日续）

报错：`failed to build: Error response from daemon: Get "https://registry-1.docker.io/v2/": Client.Timeout exceeded`。

### 根因
Docker Desktop 隔几天重启后**本地基础镜像丢失**（node/nginx 都没了），build 的 `FROM` 要去 Docker Hub 拉，但当前环境连不上 Docker Hub：
- 沙箱代理（本次 `127.0.0.1:58472`，端口每会话变）对 registry-1.docker.io 返回 000；
- 系统 Clash `7897` **未启动**（netstat 无监听）；公网直连也失败。
- **关键发现**：Docker daemon 走内部代理 `http.docker.internal:3128`，该代理能直连**国内镜像加速器**——实测 `docker pull docker.1panel.live/...` 成功（401/200 都说明通）。

### 解法（不需改任何代码，纯环境修复）
1. 从加速器拉基础镜像并打回 Dockerfile 期望的本地 tag：
   ```
   docker pull docker.1panel.live/library/node:24.22.3-trixie-slim
   docker pull docker.1panel.live/library/nginx:1.31.8-alpine-slim
   docker tag docker.1panel.live/library/node:24.22.3-trixie-slim node:24.22.3-trixie-slim
   docker tag docker.1panel.live/library/nginx:1.31.8-alpine-slim nginx:1.31.8-alpine-slim
   ```
   （本次 node 因缓存 4s 拉完）
2. 重跑 `cmd //c release.bat` → build/tag/push 全成功，退出 0，digest `sha256:162434ce...`。
3. 私有 registry `docker.ilyl.life:8443/v2/` 返回 401（正常认证挑战，说明可达，push 能成功）。

### 结果
- 镜像 40MB（反代版去掉证书后更小）；产物 441 HTML + 579 .gz + 首页齐全。
- **零代码改动**，git 工作区干净。以后再遇此报错：先确认基础镜像是否丢失 → 用 `docker.1panel.live/library/<name>` 加速器拉取并 tag 回本地名，比折腾代理更快。
- 加速器候选（均实测经沙箱代理可达）：`docker.1panel.live`(200)、`docker.m.daocloud.io`、`docker.1ms.run`、`docker.xuanyuan.me`、`hub.rat.dev`。
